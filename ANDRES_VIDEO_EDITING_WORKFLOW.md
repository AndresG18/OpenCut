# Andres' Video Editing Workflow

Use this workflow when turning multiple talking-head takes into Reels, TikToks, and YouTube Shorts.

## Editorial Rules

- Review and approve spoken passages before assembling a timeline.
- Prefer complete, confident deliveries; exclude false starts, stutters, filler, repeated lines, and mid-thought endings.
- Build modular clips first, then create several narrative permutations from those modules.
- Do not repeat the same proof point in a single version. Keep one clear explanation of how to find in-app sales data.
- Keep original media untouched. Export all edits as new files.
- For social versions, use a 9:16 crop, keep the speaker centered, and add high-contrast burned-in captions when they improve comprehension.
- Keep sound design restrained. Do not add effects unless they improve a transition or clarify an interaction.

## Studio Workflow

1. Import original takes and the approved modular clips into the project.
2. Keep the media bin as a source library; only add a clip to a timeline after approving it.
3. Keep each version independent: use a separate scene or project for each narrative permutation.
4. Apply captions after locking the spoken sequence, then export a fresh 9:16 file.
5. Name exports by editorial angle, for example `DeckTradr_Version_B_Social_Proof_9x16.mp4`.
